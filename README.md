# Home Server Infrastructure

## О проекте

Учебный проект по настройке домашнего сервера на Ubuntu Server.

## Стек

- Ubuntu Server 24.04
- Nginx
- MySQL 8
- Docker
- UFW

## Что настроено

- Пользователи и группы
- Бэкапы (tar, rsync, cron)
- Веб-сервер Nginx
- Docker + Compose
- Firewall UFW
